# STM32F030F4P6 Binary Clock Board

This board package documents the STM32F030F4P6 wiring used by the CubeMX/HAL
port of the binary clock.

## MCU Pinout

| MCU pin | Function | Notes |
| --- | --- | --- |
| PA0 | LDR ADC input | Light sensor / automatic brightness, ADC_IN0 |
| PA1 | Buttons ADC input | Five-button resistor ladder, ADC_IN1 |
| PA2 | 74HC595 SER / DS | Shift-register serial data, pin 14 |
| PA3 | 74HC595 RCLK / ST_CP | Shift-register latch clock, pin 12 |
| PA5 | 74HC595 SRCLK / SH_CP | Shift-register shift clock, pin 11 |
| PA6 | 74HC595 OE | TIM3_CH1 PWM, active-low output enable, pin 13 |
| PA7 | DS1302 CLK | RTC clock |
| PA9 | DS1302 DATA / I/O | Bidirectional RTC data |
| PA10 | DS1302 RST / CE | RTC chip enable |
| PB1 | Buzzer control | Active buzzer transistor drive |
| PF1 | DHT11 DATA | Single-wire temperature/humidity data |
| PA13 | SWDIO | Debug/programming |
| PA14 | SWCLK | Debug/programming |

## 74HC595N Chain

Two 74HC595N shift registers are chained for 16 LED outputs.

STM32F030F4P6 to first 74HC595N:

| STM32 pin | 74HC595N pin | Function |
| --- | --- | --- |
| PA2 | pin 14 | SER / DS, serial data |
| PA3 | pin 12 | RCLK / ST_CP, latch clock |
| PA5 | pin 11 | SRCLK / SH_CP, shift clock |
| PA6 | pin 13 | OE, output enable PWM |

The first byte shifted out travels through the first 74HC595 `QH'` output and
ends up in the second chip. The second byte shifted out remains in the first
chip connected directly to MCU DATA.

### LED Mapping

First 74HC595, connected directly to MCU DATA:

| Output | Display |
| --- | --- |
| QA | hours 32 |
| QB | hours 16 |
| QC | hours 8 |
| QD | hours 4 |
| QE | hours 2 |
| QF | hours 1 |
| QG | minutes 32 |
| QH | minutes 16 |

Second 74HC595, chained from first chip `QH'`:

| Output | Display |
| --- | --- |
| QA | minutes 8 |
| QB | minutes 4 |
| QC | minutes 2 |
| QD | minutes 1 |
| QE | mode time / alarm slot 1 |
| QF | mode date / alarm slot 2 |
| QG | mode environment / alarm slot 3 |
| QH | alarm status |

## Buttons ADC Ladder

The five buttons are read through one resistor ladder on `PA1 / ADC_IN1`.

Current measured ADC ranges are decoded with these thresholds:

| Button | Max ADC value |
| --- | ---: |
| MODE | 470 |
| SET | 950 |
| UP | 1630 |
| DOWN | 2330 |
| OFF | 3360 |

Values above `3360` are treated as no button.

## Light Sensor

The LDR divider is connected to `PA0 / ADC_IN0`.

Current calibration:

| Constant | Value |
| --- | ---: |
| ADC dark | 1000 |
| ADC bright | 3200 |
| Brightness min | 5% |
| Brightness max | 70% |
| Brightness levels | 6 |
| ADC hysteresis | 80 |

Brightness is applied through `PA6 / TIM3_CH1` to the 74HC595 OE pin. OE is
active-low.

## DS1302 RTC

| STM32 pin | DS1302 pin |
| --- | --- |
| PA7 | CLK |
| PA9 | DATA / I/O |
| PA10 | RST / CE |

The DS1302 stores the current time/date and the three alarm slots in
battery-backed RAM.

Alarm RAM format:

```text
byte 0  -> signature
byte 1  -> version
byte 2  -> alarm slot 1 flags
byte 3  -> alarm slot 1 hour
byte 4  -> alarm slot 1 minute
byte 5  -> alarm slot 2 flags
byte 6  -> alarm slot 2 hour
byte 7  -> alarm slot 2 minute
byte 8  -> alarm slot 3 flags
byte 9  -> alarm slot 3 hour
byte 10 -> alarm slot 3 minute
byte 11 -> checksum
```

Alarm flags:

```text
bit 0 -> configured
bit 1 -> enabled
```

## DHT11

The DHT11 data line is connected to `PF1`.

The firmware switches PF1 between open-drain output for the start pulse and
input for the DHT11 response and 40-bit data transfer. The DHT11 transaction is
guarded so a full read is not started more often than once every 2 seconds.

## Buzzer

`PB1` drives the active buzzer circuit. The alarm pattern is generated by the
application layer:

```text
beep beep beep ... pause ... beep beep beep ... pause
```
